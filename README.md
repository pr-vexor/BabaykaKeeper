# BabaykaKeeper

Продвинутый аналог Instagram Close Friends для Telegram-каналов. 
Телеграм бот для разделения аудитории, но с более гибким функционалом.

Автоматически добавляет к постам в канале кнопку "Обсудить с друзьями".
При этом сохраняет возможность нативного комментирования для всех подписчиков.
Создает изолированное пространство для свободного общения близких друзей, без ограничения их доступа к общим реакциям и комментариям к постам.

Позволяет развернуть запускаемые экземпляры бота на разных устройствах с автоматическим переключением.


## Настройка
Полная настройка приложения включает в себя следующие шаги:

### Настройка БД (Postgres в Docker)

	Поднять образ postgres в docker, используя пример \docker\docker-compose.yaml и команду docker-compose up -d
	Зарегистрировать сервер в pgAdmin или аналогичном, используя значения из раздела переменных окружения docker-compose.yaml
	
### Переменные окружения

Обязательные:

    BOT_TOKEN		 		- токен бота 			(пример: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz)
	BOT_NAME 		 		- имя бота
	OWNER_ID		 		- ID владельца канала 	(пример: 1234567890)
	CHANNEL_ID		 		- ID канала 			(пример: -1001122334455)
	PRIVATE_GROUP_ID 		- ID закрытой группы	(пример: -1006677889900)
	
Дополнительные:

	INSTANCE_NAME		 	- имя экземпляра бота
	ACTIVITY_FLAG_FILENAME 	- расположение файла-флага для активации бота
	PRIVATE_GROUP_TEXT		- текст ссылки на закрытую группу
	
#### Действия в Телеграмм

 - Создать канал
 - Добавить бота в канал и назначить администратором
 - Разрешить в канале комментарии (добавив или создав для этого группу)
 - Создать закрытую супергруппу и добавить в неё бота
   - Создать открытую группу
   - Изменить её тип на закрытую
   - Добавить в неё бота (как участника)
   - Убедиться в правильном типе группы можно, вызвав команду /getchatid
   	 - (id должен быть в итоге как у канала - начинаться с -100):
 - Для получения OWNER_ID написать боту @RawDataBot или боту @userinfobot
 - Для получения CHANNEL_ID переслать любое сообщение из канала в бот @RawDataBot 
 - Для получения PRIVATE_GROUP_ID вызвать из закрытой группы команду /getchatid
